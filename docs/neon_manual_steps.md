### Step 4: Migration 0037 (`0037_institution_alias`)
**[RUN ON NEON BRANCH FIRST]**

Django Command (on Neon branch):
```bash
python manage.py migrate api 0037
```

Equivalent PostgreSQL DDL (`sqlmigrate api 0037`):
```sql
BEGIN;
CREATE TABLE IF NOT EXISTS "api_institution_alias" (
    "id" bigint NOT NULL PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
    "alias" varchar(100) NOT NULL,
    "eiin" varchar(50) NOT NULL,
    "source_note" varchar(255) NOT NULL,
    "institution_id" bigint NULL REFERENCES "api_institution" ("id") DEFERRABLE INITIALLY DEFERRED,
    CONSTRAINT "api_institution_alias_alias_eiin_uniq" UNIQUE ("alias", "eiin")
);

CREATE INDEX IF NOT EXISTS "api_institution_alias_alias_idx" ON "api_institution_alias" ("alias");
CREATE INDEX IF NOT EXISTS "api_institution_alias_eiin_idx" ON "api_institution_alias" ("eiin");
CREATE INDEX IF NOT EXISTS "api_institution_alias_institution_id_idx" ON "api_institution_alias" ("institution_id");
COMMIT;
```

### Step 6: PostgreSQL Trigram Extension & GIN Index
**[RUN ON NEON BRANCH FIRST]**

Run directly in the Neon SQL Console to enable fast substring / prefix fuzzy search across 36,500+ records:
```sql
-- Enable trigram extension (requires superuser / Neon default privilege)
CREATE EXTENSION IF NOT EXISTS pg_trgm;

-- Fast trigram GIN index for case-insensitive `ILIKE '%...%'` queries
CREATE INDEX IF NOT EXISTS api_institution_name_trgm_idx
ON api_institution USING gin (name gin_trgm_ops);

-- Fast pattern index for prefix `LIKE '...%'` queries
CREATE INDEX IF NOT EXISTS api_institution_name_prefix_idx
ON api_institution (name varchar_pattern_ops);
```
