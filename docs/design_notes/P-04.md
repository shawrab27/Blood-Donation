# Design Note P-04: Blood Hub Search Donor Card Redesign & Privacy Guard
**Problem:** In Blood Hub > Search for Blood, result cards were full-width white cards with non-compliant styling, lacked the 2-per-row dark red design, and had unneeded campus filters.
**Approach:**
1. Screen: Update `DonorSearchScreen` background to soft light (`#FDF3F3`), ensure 2-per-row grid layout using `CompactDonorCard` (or shared `DonorCard`), preserve skeleton loading, and empty state. Remove campus filter in favor of nationwide division & zila.
2. Card: Dark red `#C30121` background, white text (`>= 4.5:1` contrast), small compact pill/card showing strictly 4 allowed fields (name, blood group, district, tier). Tapping opens popup.
3. Popup: Detailed bottom sheet dialog showing ONLY the 4 privacy fields (district name, donor name, blood group, platform tier) + "Request Blood" button. No phone, no exact location.
**Data Flow:**
- Query -> `donorSearchNotifierProvider` -> returns `DonorSearchModel` list -> 2-per-row dark red cards -> tap card -> opens `showDonorDetailPopup` -> tap "Request Blood" -> navigates to `/blood-hub/request/direct`.
**Failure Cases:**
- Empty list: Renders clean empty state with clear filters CTA.
- Text scale 1.3 / narrow viewports: `FittedBox` / `TextOverflow.ellipsis` and flexible grid aspect ratios prevent `RenderFlex` overflows.
