# Design Note: H-02 (Session, Navigation, Localization, Seed Fixes)
- Problem: S1/S3 session loss on profile/restart, S2 phone back exiting instead of popping/stepping, S4 missing/incomplete language toggle & strings, S5 location seed crash on malformed upazila.
- Approach: Resilient token persistence (secure + pref fallback) & refresh-only logout; stack-preserving navigation with back handling & registration PopScope; ubiquitous EN/BN toggle & localized strings; atomic clean upazila seeding.
- Data Flow: Storage/tokens -> ApiClient -> AuthNotifier/Router; PopScope -> PageController/Navigator; LocaleNotifier -> ARB -> UI; bd_upazilas -> atomic seed_bd_locations.
- Failure Cases: Keystore wipe (fallback to prefs), token refresh 401 (graceful logout), detail pop on root (tab-to-feed or confirm), corrupted upazila entry (atomic rollback + stderr diagnostics).
